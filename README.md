# SQL-EXERCISE-03-CASE-Statement
Case statement sql questions
Project Overview
This repository contains questions and table answers demonstrating the use of SQL CASE expression — SQL's way of classifying rows into labelled buckets. The goal of this exercise was to develop a deeper understanding of how to summarise and analyse data using SQL with - case statement.

The exercise includes 10 practical questions across multiple datasets: 
-Products, 
-Orders,
-employees,
-students,
-deliveries,
-tickets,
-attendance,
-product_inventory,
-Classes,
-Payments

 CASE statement is used with comparison operators such as :
 -BETWEEN,
 -AND, 
 -OR 
 -AS to alias the CASE statement has been used
